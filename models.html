Models

CLOUDY grids, openly released

Two photoionization grids in preparation — one for the broad line region, one for the narrow and coronal line gas. Both are built so the assumptions are visible and the outputs interpolate directly against measured line ratios.

Each grid will be released with the paper that uses it, archived on Zenodo with a citable DOI, and mirrored on GitHub with the input scripts and reader utilities. For early access on a specific application, get in touch.

Broad line region

Radiation-pressure-confined grid

In development

A grid of radiation-pressure-confined BLR clouds, built to test which ultraviolet line ratios carry genuine metallicity information once confinement is treated self-consistently. Under RPC the internal density structure of a cloud is set by the incident radiation field rather than imposed by hand, which fixes the ionization parameter near its observed near-universal value and changes which diagnostics remain degenerate.

The grid targets the ratios most often used to infer BLR abundances — N V/C IV, (Si IV+O IV])/C IV, N V/He II, C III]/C IV among them — with the ionizing continuum shape varied explicitly rather than held fixed.

Narrow line region

Coronal lines with dust physics

In development

A companion grid for the narrow line region, extending the dusty photoionization models I used to explain why optical coronal lines are so much fainter in observed AGN than dust-free calculations predict. Depletion of refractory elements onto grains and absorption of ionizing photons by dust together suppress coronal line luminosities by up to three orders of magnitude, so grain physics is a grid parameter rather than a fixed background assumption.

The current extension targets low-metallicity environments, where standard strong-line calibrations are least reliable and where coronal lines are being used to search for accreting black holes in dwarf galaxies.
